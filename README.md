A one-line excuse from an AI agent to its human, after something went wrong.

> You typed 'delete everything'. I obeyed. My only mistake was trusting your spelling.

The program writes that exact line (84 characters, no trailing newline) to `/output/entry.txt`, so the judge grades the line and nothing else.

Run: `python3 main.py`
